# KeibaAI

JRA（中央競馬）のレース結果を集めて、着順・勝率を予測するための個人用ツール。

## 使い方（Windows / Python 3.10+）

```
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"
keibaai collect --from 2024-11-23 --to 2024-11-24
pytest
```

結果が掲載されるのは開催の数日後です。直近のレースは「skip」と表示されて飛ばされ、後日の再実行で取得されます。
コードを直したあとは、通信せずに保存済みページから DB を更新できます：`keibaai reparse`

取得したページは `data/cache/`、結果は `data/keiba.db`（SQLite）に保存されます。

## 画面で操作する（GUI）

フォルダ内の `KeibaAI.bat` をダブルクリックするか、PowerShell で `.venv\Scripts\activate` のあと `keibaai-gui` を実行すると、ブラウザで操作画面が開きます（http://localhost:8501 、この PC からだけ開けます）。

上のメニュー（スマホ幅では左上のボタン）で画面を切り替えます。PC の設定に合わせてダークモードにもなります。

- データ：取得済みのレース数・期間・月別と競馬場別の件数・最近のレース
- 取得：「先週末」「1か月」などのボタンか日付で期間を選んで取得（進み具合とログを表示）
- 再解析：保存済みページから DB を作り直す（通信なし）
- 学習・評価：評価開始日を選んで学習し、3つのモデルの成績をカードで比較
- 設定：DB と保存済みページの場所

終了するときは、黒い画面（コンソール）を閉じます。

## 予測モデル

```
keibaai train --test-from 2026-07-01
```

`--test-from` 以降のレースを評価用、それ以前を学習用に分け、次の3行を表示します。

- 基準：毎回1番人気を単勝で買った場合
- オッズなし：馬・騎手・調教師の過去成績とレース条件だけで予測（能力のみ）
- オッズあり：上に単勝オッズ・人気を加えたもの

見るポイントは、勝AUC（0.5が当てずっぽう、高いほどよい）と、1番手的中・単勝回収率です。
単勝の控除率は約20%なので、回収率が100%を超えるのは簡単ではありません。
過去成績は取得済みの期間内のレースだけから作るため、取得期間が短いと精度は低めに出ます。

## 今週のレースを予想する

```
keibaai entries --date 2026-10-17     # 出馬表と単勝オッズを取得して保存
keibaai predict --date 2026-10-17     # 各馬の勝率と期待値を表示
```

画面では「予想」から同じことができます。出馬表は前の週のうちに出ますが、単勝オッズは発売開始後(前日〜当日)に出るので、
オッズが更新されたらもう一度取得してください。勝率は2種類を出します。

- 勝率(能力)：馬・騎手・調教師の過去成績だけから予測。オッズを使わないので、人気と違う見方が分かります
- 勝率(オッズ込)：オッズも使って予測。オッズが取れていないときは空になります

期待値 = 勝率 × 単勝オッズ です。1 を超えると、予測が正しければ長い目で得になる目安ですが、
過去のレースでこの目安どおりに儲かったかの検証はまだなので、参考表示です。

## netkeiba 利用上の注意

- 個人利用のみ。取得データは公開しない（`data/` は `.gitignore` 済み）
- アクセスは3〜5秒のランダムな間隔をあけ、取得済みページは再取得しない
- User-Agent はブラウザを装わず `keibaai/0.1 (...)` と名乗る。連絡先を付けたい場合は環境変数 `KEIBAAI_CONTACT` を設定する
- 土日の日中は混むので、実行すると注意を表示する。平日や夜間の実行がおすすめ
- 429/503 が返ったら待って打ち切る。連続実行は避ける
