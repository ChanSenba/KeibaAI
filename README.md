# KeibaAI

JRA（中央競馬）の過去の成績・血統・調教タイムから、各馬の勝率を予測し、買い方（券種と金額）を計算する個人用ツール。
Windows で動きます。ソフトは無料のもの（Python・LightGBM・SQLite・Streamlit）だけを使い、データは JRA-VAN Data Lab（有料）と netkeiba から入れます。

## 何ができるか

- 予想：出馬表とオッズから、各馬の勝率と期待値（勝率 × 単勝オッズ）を出す
- 買い方：1レースの全券種のオッズから、期待値が1を超える買い目と金額（ケリー基準）を出す
- 検証：過去のレースで買い方のルールを再現し、的中率・回収率・最大の落ち込みを見る
- 毎週の自動実行：予想を保存 → 結果と照合 → 回顧を書く
- 画面（GUI）：上のすべてをブラウザから操作できる

## データの入手元

| データ | 入手元 | 備考 |
|---|---|---|
| レース成績・血統・調教タイム | JRA-VAN Data Lab（有料。JV-Link 経由） | 数分で終わる。アクセス間隔の制約なし |
| 出馬表・当日オッズ・全券種オッズ | netkeiba（個人利用の範囲で取得） | 3〜5秒おき。→「netkeiba 利用上の注意」 |

JRA-VAN の利用キーは、JV-Link の設定画面にご自分で入力します（このツールはキーを扱いません）。

## はじめに（Windows / Python 3.10+）

```
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"
pytest
```

画面で操作するには、フォルダ内の `KeibaAI.bat` をダブルクリックするか、`keibaai-gui` を実行します
（ブラウザで http://localhost:8501 が開く。この PC からだけ見られる）。終了は黒い画面（コンソール）を閉じます。

## 1. JRA-VAN から取り込む（調教タイム・過去の成績・血統）

JRA-VAN Data Lab を契約し、JV-Link を入れて利用キーを設定した PC で使えます。
JV-Link は 32bit の部品なので、32bit 版 Python が別に要ります（python.org の「Windows installer (32-bit)」を `C:\Python311-32` などに入れ、
`C:\Python311-32\python.exe -m pip install pywin32`）。場所は `--python32` で指定します。

```
keibaai jv --what training races pedigree --from 20190101 --python32 C:\Python311-32\python.exe
keibaai jv --what training races pedigree --from 20261001 --option 1 --rt-days 4 --python32 C:\Python311-32\python.exe   # 毎週の差分
```

`--from` は取得を始める日です。毎週の差分では、前回取り込んだ日より少し前の日付を指定します（重なった分は上書きされるだけです）。

| `--what` | 内容 | 取り込み方 |
|---|---|---|
| `training` | 坂路・ウッドの調教タイム | 追加・上書き（5万件ごとに確定） |
| `races` | レース成績（確定した中央のレースのみ） | DB に無いレースだけ足す（`--replace` で入れ替え） |
| `pedigree` | 全馬の血統（3代） | 書き出しに入っていた馬を上書き（netkeiba の番号の行は消す） |

- 最初の `races`（`--option 4`、既定）は、同じデータ種別に入っているオッズ・投票の大きなファイルを1つずつ開いて飛ばすため、長くかかります（2019年以降で約30分）。調教タイムと血統は数分です。毎週の差分（`--option 1`）は短く済みます。
- JV-Link を短い時間に何度も開き直すと、JVOpen が -303 を返して開けなくなることがありました（原因は未確認）。続けて試さず、時間をおいてください。
- レース ID と馬・騎手・調教師の番号は netkeiba と同じです。netkeiba から集めた 10,371 レースと突き合わせ、着順・タイム・オッズ・馬体重・ラップが一致することを確かめてあります。着差は入りません。
- 血統の番号は JRA-VAN の繁殖登録番号で、netkeiba の馬 ID とは別の体系です。**取り込んだあとは `keibaai pedigree`（netkeiba）を使わないでください。** 混ざると同じ種牡馬が別扱いになります。また、血統が一部の馬にしか入っていない状態は、予想をかえって悪くします（検証では、出走の 46% にだけ血統がある状態で総合の AUC が 0.786 → 0.775。全頭ぶん入れると 0.788）。
- 取り込んだデータは個人利用のみ。公開しない（`data/` は `.gitignore` 済み）。

## 2. 予測モデル

```
keibaai train --test-from 2026-07-01
```

`--test-from` 以降を評価用、それ以前を学習用に分け、次の3行を表示します。

- 基準：毎回1番人気を単勝で買った場合
- オッズなし：馬・騎手・調教師の過去成績、血統、調教タイム、レース条件だけで予測（能力のみ）
- オッズあり：上に単勝オッズ・人気を加えたもの

見るポイントは、勝AUC（0.5が当てずっぽう、高いほどよい）と、1番手的中・単勝回収率です。
どの特徴量も、そのレースより前の結果だけから作ります（テストで確認）。

### 調教タイム（JRA-VAN）の特徴量

直近14日の速い追い切り（坂路は4F 58秒以内、ウッドは56秒以内）の本数と速さ、15〜180日前の基準との差（3本以上ある馬のみ）、同じレースの出走馬との差など、8つ。
特に新馬戦で効きます。

### 要素ごとの予想

```
keibaai factors --test-from 2026-01-01
```

要素だけを使ったモデルで勝率を別々に出し、「総合」と並べて当たりやすさを比べます。

- 馬の質 / 適性 / ローテーション / 騎手・厩舎 / 展開・馬場 / 血統 / 調教タイム

画面の「ファクター」ページでは、出馬表を取得した日のレースを選ぶと、馬ごとの値が区分別のタブで見られます（学習しないのですぐ開く）。

### 検証で分かっていること（過去8年、確定オッズ）

- 血統を全頭に入れ、調教タイムを足し、学習に使う成績を 2019年以降（約7年）に増やすと、能力のみのモデルの勝AUC は 0.785 → 0.80 前後に上がり、1番手の的中率は 26% 前後から 28〜29% になります。2014年までさかのぼっても、それ以上はほぼ伸びません。そのぶん学習や予想は長くかかります（`train` が 11秒 → 35秒）。
- オッズを含めたモデルは、オッズだけのモデルを8年すべてで上回ります（ただし LogLoss の差は 0.0001〜0.0007 とわずか）。
- 特徴量の候補は `python -m keibaai.feature_trials --db data/keiba.db` で、足す前後を比べられます（DB は読むだけ）。2026年10月の検証では、厩舎×騎手の3着内率を回数の少なさで割り引く補正（k=50）だけが、能力のみのモデルで確かに効きました（AUC +0.0008〜0.0009）。当日の先行レースの偏り、強い馬を差し引いた偏り、コースごとの偏り、騎手×種牡馬・調教師×種牡馬、レースレベル、開催日、天候と季節、騎手の格差、前走の RPCI は、誤差の範囲でした。
- 単勝100円の回収率：全頭 72.7%、1番人気 79.6%、能力のみのモデルで選ぶと 79.5%（当てずっぽう並み）、オッズ込みモデルで期待値の高い馬を選ぶと 93〜97%。**100%を超える選び方は見つかっていません。**
- 馬連 90.6%、ワイド 90.7%。画面の期待回収率は実際より 2〜3 割高く出ます。
- 確定オッズでの計算なので、買う時点のオッズでは、さらに下がる見込みです。

## 3. 今週のレースを予想する

```
keibaai entries --date 2026-10-17     # 出馬表と単勝オッズを取得して保存（JV-Link のある PC では JRA-VAN から）
keibaai entries --date 2026-10-17 --source netkeiba   # netkeiba から取る
keibaai predict --date 2026-10-17     # 各馬の勝率と期待値を表示
```

画面では「予想」から同じことができます。単勝オッズは発売開始後（前日〜当日）に出るので、更新されたらもう一度取得してください。
勝率は2種類を出します。

- 勝率(能力)：オッズを使わないので、人気と違う見方が分かる
- 勝率(オッズ込)：オッズも使う。オッズが取れていないと空になる

期待値 = 勝率 × 単勝オッズ です。1 を超えると、予測が正しければ得になる目安です。
画面の ★ は、オッズ込みの期待値 1.1 以上・勝率 3% 以上・単勝オッズ 30 倍以下の馬に付きます。★ の過去の回収率は 93〜97% で、買えば儲かるという印ではありません。

## 4. 買い方を出す

「予想」ページで予想したあと、「買い方」ページでレースを選んで「買い方を出す」を押します。
そのレースの全券種（単勝・複勝・馬連・ワイド・馬単・三連複・三連単）のオッズを取得し（6回アクセス）、次の順に計算します。

1. オッズ込みのモデルの勝率と、いま取ったオッズの確率を混ぜた勝率を作る（混ぜ方は直前12か月の結果で決める。能力のみのモデルは、混ぜても重みがほぼ0になり、オッズに何も足せなかった）
2. 勝率から、1〜3着の並びの確率を出す（ハーヴィルの式を、人気馬の2〜3着を少し抑えたヘネリー版にしたもの）
3. 買い目ごとに 期待値 = 的中確率 × 当日オッズ を出し、1を超えるものだけを候補にする
4. 候補の中から、資金が長い目で最も増える配分（ケリー基準。既定は半分に抑える）を求め、100円単位にする

```
keibaai bets --date 2026-10-17 --race-id <race_id>      # 先に keibaai entries --date ...
```

出力は、買い目・金額・どれか的中する確率・期待回収率・全部外れたときの損失です。期待値が1を超える買い目がなければ「見送り」と表示します。
複勝とワイドは、幅のあるオッズの下限で計算します。2〜3着の確率の式の定数は文献の値で、JRA の払戻で確かめたものではありません。
**期待回収率は「予想が当たっている前提」の数字で、過去の検証での実際の回収率は 90% 前後でした。**

## 5. 買い方のシミュレーション

```
keibaai backtest --test-from 2026-01-01            # 1番人気 / ◎ / 期待値≧1.0・1.2・1.5 / 全頭 を比べる
keibaai backtest --test-from 2026-01-01 --ev 1.0 --max-odds 30 --market
```

過去のレースに単勝のルールを当てはめ、毎回 100 円買い続けた場合の的中率・回収率・収支・最大の落ち込みを出します。
学習は `--test-from` より前だけ、買うのはそれ以後だけです。回収率には、買い目を引き直して求めた 95% の幅も付きます。
`--blend` は、モデルの勝率と市場の確率をレースごとの対数オッズで混ぜます（ベンター方式）。`--market` はオッズ込みのモデルを使います。

基準をいくつも試して良い結果だけを選ぶと、たまたまの当たりを拾います。基準は先に決めてから一度だけ評価してください。

## 6. 毎週の自動実行（予想 → 結果と照合 → 回顧）

```
keibaai weekly
```

1回の実行で、次のことをします。何度実行しても、済んだ分は飛ばします。

1. 予想を保存した日のうち、今日より前の日の結果を取得し、予想と照合して `data/reviews/<日付>.md` に回顧を書く
2. 今週末（土・日）の出馬表とオッズを取得して予想を作り、DB に保存する（出馬表がまだなら飛ばす）

予想は、発走前の内容のまま残します。回顧は事実（◎の着順、勝ち馬の予想順位・オッズ、期待値で買った場合の収支など）だけをまとめます。

Windows のタスクスケジューラに登録するには、次を1度だけ実行します（木曜と月曜の夜 21 時）。

```
schtasks /Create /TN "KeibaAI weekly" /SC WEEKLY /D THU,MON /ST 21:00 /TR "\"C:\パス\KeibaAI\KeibaAI-weekly.bat\""
```

`C:\パス\KeibaAI` はこのフォルダの場所に置き換えてください。記録は `data\weekly.log` に残ります。PC が起動していないと動きません。

## 画面（GUI）

上のメニュー（スマホ幅では左上のボタン）で切り替えます。PC の設定に合わせてダークモードにもなります。

- データ：取得済みのレース数・期間・月別と競馬場別の件数
- 取得 / 再解析：netkeiba からの取得、保存済みページからの DB の作り直し（通信なし）
- 学習・評価：評価開始日を選んで学習し、3つのモデルの成績を比較
- 予想 / 買い方 / ファクター / シミュレーション / 回顧：上の各節の画面版

## netkeiba 利用上の注意

- 個人利用のみ。取得データは公開しない（`data/` は `.gitignore` 済み）
- アクセスは3〜5秒のランダムな間隔をあけ、取得済みページは再取得しない
- User-Agent はブラウザを装わず `keibaai/0.1 (...)` と名乗る。連絡先を付けたい場合は環境変数 `KEIBAAI_CONTACT` を設定する
- 土日の日中は混むので、実行すると注意を表示する。平日や夜間の実行がおすすめ
- 429/503 が返ったら待って打ち切る。連続実行は避ける
- ログインやパスワードは扱わない

`keibaai collect`（レース結果）・`entries`（出馬表と単勝オッズ）・`weekly` は、JV-Link のある PC では JRA-VAN から取ります
（`--source auto` が既定。`--source netkeiba` で netkeiba に戻せます。32bit Python は `C:\Python311-32\` から探し、環境変数 `KEIBAAI_PYTHON32` でも指定できます）。
画面の「データ取得」「予想」にも取得元の切り替えがあります（既定は JRA-VAN）。
netkeiba だけから取るのは、`keibaai training`（調教の評価 A〜D。JRA-VAN にない項目）と、買い目ページの全券種のオッズ（JRA-VAN への切り替えは準備中）です。
成績・血統・調教タイムは JRA-VAN に切り替え済みです。`pedigree` は JRA-VAN の血統と番号が合わないため使いません。
