# KeibaAI

JRA（中央競馬）のレース結果を集めて、着順・勝率を予測するための個人用ツール。

## 使い方（Windows / Python 3.10+）

```
python -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"
keibaai collect --from 2024-11-23 --to 2024-11-24
pytest
```

結果が掲載されるのは開催の数日後です。直近のレースは「skip」と表示されて飛ばされ、後日の再実行で取得されます。
コードを直したあとは、通信せずに保存済みページから DB を更新できます：`keibaai reparse`

取得したページは `data/cache/`、結果は `data/keiba.db`（SQLite）に保存されます。

## 画面で操作する（GUI）

フォルダ内の `KeibaAI.bat` をダブルクリックするか、PowerShell で `.venv\Scripts\activate` のあと `keibaai-gui` を実行すると、ブラウザで操作画面が開きます（http://localhost:8501 、この PC からだけ開けます）。

上のメニュー（スマホ幅では左上のボタン）で画面を切り替えます。PC の設定に合わせてダークモードにもなります。

- データ：取得済みのレース数・期間・月別と競馬場別の件数・最近のレース
- 取得：「先週末」「1か月」などのボタンか日付で期間を選んで取得（進み具合とログを表示）
- 再解析：保存済みページから DB を作り直す（通信なし）
- 学習・評価：評価開始日を選んで学習し、3つのモデルの成績をカードで比較
- 設定：DB と保存済みページの場所

終了するときは、黒い画面（コンソール）を閉じます。

## 予測モデル

```
keibaai train --test-from 2026-07-01
```

`--test-from` 以降のレースを評価用、それ以前を学習用に分け、次の3行を表示します。

- 基準：毎回1番人気を単勝で買った場合
- オッズなし：馬・騎手・調教師の過去成績とレース条件だけで予測（能力のみ）
- オッズあり：上に単勝オッズ・人気を加えたもの

見るポイントは、勝AUC（0.5が当てずっぽう、高いほどよい）と、1番手的中・単勝回収率です。
単勝の控除率は約20%なので、回収率が100%を超えるのは簡単ではありません。
過去成績は取得済みの期間内のレースだけから作るため、取得期間が短いと精度は低めに出ます。

## 今週のレースを予想する

```
keibaai entries --date 2026-10-17     # 出馬表と単勝オッズを取得して保存
keibaai predict --date 2026-10-17     # 各馬の勝率と期待値を表示
```

画面では「予想」から同じことができます。出馬表は前の週のうちに出ますが、単勝オッズは発売開始後(前日〜当日)に出るので、
オッズが更新されたらもう一度取得してください。勝率は2種類を出します。

- 勝率(能力)：馬・騎手・調教師の過去成績だけから予測。オッズを使わないので、人気と違う見方が分かります
- 勝率(オッズ込)：オッズも使って予測。オッズが取れていないときは空になります

期待値 = 勝率 × 単勝オッズ です。1 を超えると、予測が正しければ長い目で得になる目安ですが、
過去のレースでこの目安どおりに儲かったかの検証はまだなので、参考表示です。

## 要素ごとの予想

```
keibaai factors --test-from 2026-01-01
```

勝率を、次の要素だけを使ったモデルで別々に出し、「総合」と並べて当たりやすさを比べます。
- 馬の質: 過去の着順・上がり順位・タイム差・位置取りの上がり、馬体重の変化、斤量体重比、前走の人気と着順の差など
- 適性: 距離・芝ダート・回り・競馬場・馬場状態ごとの過去の3着以内率、距離の短縮・延長(300m以上)
- ローテーション: レース間隔(週)、連闘、休み明け何戦目
- 騎手・厩舎: 騎手の成績(コース別・距離別・競馬場別)、騎手の単勝回収率(過剰人気の目安)、騎手と馬の相性、厩舎と騎手の組み合わせ、乗り替わり
- 展開・馬場: 枠順・馬番、脚質(前に付ける率・差す率)、出走馬の脚質の組み合わせ(先行馬の数など)、トラックバイアス、過去のレースのラップ(前半3F−後半3F)と自分の上がりの速さ
- 血統: 父・母の父の産駒の、同じ条件(芝/ダート×距離帯・馬場)での過去の3着以内率

`keibaai predict` と画面の予想には、要素ごとの勝率の列が付きます。
「総合+全要素」は、総合に上のすべてを足したモデルです。これが総合より良くなるかを実データで確かめます。
トラックバイアスは、同じ競馬場・同じ芝/ダートの直近10日以内の前の開催日の偏りで、当日のレースは使いません(出走前に分からないため)。
どの特徴量も、そのレースより前の結果だけから作ります(テストで確認)。
調教は、まだデータを集めていないので入っていません。

### 画面で見る(ファクターページ)

`keibaai-gui` の「ファクター」ページで、出馬表を取得した日のレースを選ぶと、馬ごとの値が区分別のタブで見られます。
脚質(推定)・馬齢・体重、条件ごとの着度数、近5走とローテーション、騎手のリーディング順位と相性、馬場・枠・ペース予想、オッズのゆがみ、血統、ラップ。
上のカードで、区分ごとにデータが揃っているかも分かります(調教は未取得、血統は取得した頭数を表示)。学習はしないので、すぐ開きます。

### 血統とラップのデータを集める

```
keibaai reparse                  # 取得済みのレースページからラップを読み直す(通信なし)
keibaai pedigree --limit 20      # まず20頭だけ試す
keibaai pedigree                 # 全頭。出馬表の馬が先。止めても続きから再開できる
```

血統は馬ごとに1ページ(3〜5秒おき)で、全頭だと半日ほどかかります。夜間や平日にまとめて回してください。
取得したページは `data/cache/ped/` に残り、二度目からは通信しません。血統が未取得の馬は、血統の列が空のまま予想されます。

## 毎週の自動実行(予想 → 結果と照合 → 回顧)

```
keibaai weekly
```

1回の実行で、次のことをします。何度実行しても、済んだ分は飛ばします。
1. 予想を保存した日のうち、今日より前の日の結果を取得し、予想と照合して `data/reviews/<日付>.md` に回顧を書く
2. 今週末(土・日)の出馬表とオッズを取得して予想を作り、DB に保存する(出馬表がまだなら飛ばす)

予想は、発走前の内容のまま残します(開催日の9時以降と、開催日が過ぎたあとは書き換えません)。
回顧は事実(◎の着順、勝ち馬の予想順位・オッズ、期待値で買った場合の収支など)だけをまとめます。画面の「回顧」でも見られます。

Windows のタスクスケジューラに登録するには、次を1度だけ実行します(木曜と月曜の夜 21 時。出馬表は木曜夕方以降に確定するため)。

```
schtasks /Create /TN "KeibaAI weekly" /SC WEEKLY /D THU,MON /ST 21:00 /TR "\"C:\パス\KeibaAI\KeibaAI-weekly.bat\""
```

`C:\パス\KeibaAI` はこのフォルダの場所に置き換えてください。実行の記録は `data\weekly.log` に残ります。
PC が起動していないと動きません。動かなかった週は、あとで `keibaai weekly` を実行すれば取り戻せます。
## 買い方のシミュレーション

```
keibaai backtest --test-from 2026-01-01            # 1番人気 / ◎ / 期待値≧1.0・1.2・1.5 / 全頭 を比べる
keibaai backtest --test-from 2026-01-01 --ev 1.0 --max-odds 30 --market
```

過去のレースに買い方のルールを当てはめ、単勝を毎回 100 円買い続けた場合の的中率・回収率・収支・最大の落ち込みを出します。
学習は `--test-from` より前だけ、買うのはそれ以後だけです。回収率には、買い目を引き直して求めた 95% の幅も付きます。
画面では「シミュレーション」から、同じことを収支の推移グラフ付きで見られます。

`--blend` を付けると、モデルの勝率と、オッズから出した市場の確率を、レースごとの対数オッズで混ぜた勝率を使います(ベンター方式)。
混ぜる割合は、評価開始日の前の1年の結果で決め(その前だけで学習したモデルを使う)、評価期間の結果は使いません。
市場だけ・モデルだけ・混ぜた確率の LogLoss と AUC も並べて表示します。画面では、勝率のモデルで「オッズと混ぜる」を選べます。

注意: オッズは確定オッズです。買う時点のオッズより低いことが多く、実際の成績は表より悪くなりがちです。
基準をいくつも試して良い結果だけを選ぶと、たまたまの当たりを拾うので、基準は先に決めてから一度だけ評価してください。

## 1レースの買い方を出す(買い方ページ)

「予想」ページで予想したあと、「買い方」ページでレースを選んで「買い方を出す」を押します。
そのレースの全券種(単勝・複勝・馬連・ワイド・馬単・三連複・三連単)のオッズを取得し(6回アクセス)、次の順に計算します。

1. モデルの勝率とオッズの確率を混ぜた勝率を作る(混ぜ方は直前12か月の結果で決める)
2. 勝率から、1〜3着の並びの確率を出す(ハーヴィルの式を、人気馬の2〜3着を少し抑えたヘネリー版にしたもの)
3. 買い目ごとに 期待値 = 的中確率 × 当日オッズ を出し、1を超えるものだけを候補にする
4. 候補の中から、資金が長い目で最も増える配分(ケリー基準。既定は半分に抑える)を求め、100円単位にする

出力は、買い目・金額・どれか的中する確率・期待回収率・全部外れたときの損失です。
期待値が1を超える買い目がなければ「見送り」と表示します(控除率があるので、そういうレースが多いはずです)。
複勝とワイドは、幅のあるオッズの下限で計算します。2〜3着の確率の式の定数は文献の値で、JRA の払戻で確かめたものではありません。
期待回収率は「予想が当たっている前提」の数字です。過去の検証では、勝率の見立てはオッズを大きくは上回っていません。

## netkeiba 利用上の注意

- 個人利用のみ。取得データは公開しない（`data/` は `.gitignore` 済み）
- アクセスは3〜5秒のランダムな間隔をあけ、取得済みページは再取得しない
- User-Agent はブラウザを装わず `keibaai/0.1 (...)` と名乗る。連絡先を付けたい場合は環境変数 `KEIBAAI_CONTACT` を設定する
- 土日の日中は混むので、実行すると注意を表示する。平日や夜間の実行がおすすめ
- 429/503 が返ったら待って打ち切る。連続実行は避ける

## 状態
