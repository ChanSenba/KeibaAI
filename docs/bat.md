# bat ファイルの説明書

フォルダの直下に bat ファイルが3つあります。どちらも、このフォルダの `.venv`(README の「はじめに」で作る Python の環境)を使います。
bat は黒い画面(コンソール)で動くので、文字化けしないように、先頭で文字コードを UTF-8(`chcp 65001`)にしています。

| ファイル | 一言で | 使うとき |
|---|---|---|
| `KeibaAI.bat` | 操作画面(GUI)をブラウザで開く | 予想・取得・検証などを画面で操作したいとき |
| `KeibaAI-weekly.bat` | 毎週の処理(回顧と今週末の予想)を実行する | タスクスケジューラに登録して自動で動かす。手で動かしてもよい |
| `KeibaAI-sunday.bat` | 日曜の最終レース後に、今日の回顧と学習・評価を実行する | タスクスケジューラに登録して自動で動かす(日曜 18:30) |

---

## KeibaAI.bat

### 何をするか

1. このフォルダに移動する(どこから起動しても、bat のあるフォルダで動く)
2. `.venv\Scripts\python.exe` があるか確かめる。なければメッセージを出して終了する
3. `PYTHONPATH` をこのフォルダの `src` にする(取得中で `pip install -e .` ができないときも、いまのソースで起動できる)
4. 画面用のライブラリ(streamlit)と、予想のニューラルネット用の PyTorch(CPU 版、約200MB)が入っていなければ、`pip install` で入れる。`keibaai.exe` は置き換えないので、取得の実行中でも失敗しない
5. `python -m keibaai.gui` で画面を起動する。ブラウザで <http://localhost:8501> が開く(この PC からだけ見られる)

### いつ使うか

画面で操作するとき。取得・予想・買い方・ファクター・過去レース・学習・回顧・シミュレーションは、すべて画面から使えます。
画面の使い方は、画面の上のメニューの「ヘルプ」にあります。

### 前提

- README の「はじめに」で `.venv` を作ってあること(`python -m venv .venv` と `pip install -e ".[dev]"`)
- 取得・予想をするなら、JRA-VAN の JV-Link と 32bit Python が入っていること(README の「1. JRA-VAN から取り込む」)。入っていなくても、取得済みのデータを見る画面は使える
- ポート 8501 が空いていること

### 終わらせ方

黒い画面(コンソール)を閉じる。ブラウザのタブを閉じるだけでは、裏で動き続けます。

### うまくいかないとき

| 黒い画面の表示・症状 | 原因と対処 |
|---|---|
| 「.venv が見つかりません」と出て止まる | `.venv` がない。README の「はじめに」の手順で作る。フォルダを移動・コピーしたあとは、`.venv` も作り直す(`.venv` は場所に依存する) |
| `pip install` の途中でエラーが出る | ネットワークに繋がっていない、または pip が古い。繋がっているのに失敗するときは、`.venv\Scripts\python.exe -m pip install "streamlit>=1.50"` を手で実行して、出るメッセージを見る |
| 画面が開かない・「Port 8501 is already in use」 | 前回の画面が裏で動いている。前の黒い画面を閉じる。それでも残るときは、タスクマネージャーで `python.exe` を終了する |
| `ModuleNotFoundError: keibaai` | `PYTHONPATH` が効いていない。bat をほかの場所へコピーして使っていないか確認する(bat はプロジェクトのフォルダに置いたまま使う) |
| 起動直後に黒い画面が消える | bat は異常終了のときだけ `pause` で止まる。消えるときは、コマンドプロンプトから `KeibaAI.bat` を実行して、メッセージを見る |
| 画面の中で「JV-Link を呼べない」と出る | bat ではなく、JV-Link / 32bit Python の問題。README の「1. JRA-VAN から取り込む」を参照 |

## KeibaAI-weekly.bat

### 何をするか

1. このフォルダに移動し、`data` フォルダがなければ作る
2. `PYTHONPATH` をこのフォルダの `src` にする
3. `keibaai weekly` を実行する。出力は画面に出さず、すべて `data\weekly.log` の末尾に追記する(成功も失敗も)

`keibaai weekly` の中身は次の2つです。何度実行しても、済んだ分は飛ばします。

1. 予想を保存した日のうち、今日より前の日の結果を取得し、予想と照合して `data\reviews\<日付>.md` に回顧を書く(結果がまだ出ていなければ、次回に回す)
2. 今週末(土・日)の出馬表とオッズを取得して予想を作り、DB に保存する(出馬表がまだなら飛ばす)

予想は、発走前の内容のまま残ります。

### いつ使うか

- 木曜と月曜の夜 21 時にタスクスケジューラで自動実行するのがふつうの使い方(下の登録手順)
- 動かなかった週は、あとから手でダブルクリックしても取り戻せる
- 実行は画面の「回顧」ページに反映される

### 前提

- `.venv` があること(KeibaAI.bat と同じ)
- JV-Link と 32bit Python が使えること(`keibaai weekly` は JRA-VAN から取るため、使えないと止まる)
- PC が起動していて、JV-Link が使える状態であること(PC が起動していないと動かない)
- 出馬表は、馬番が金曜の枠順の発表後に入る。木曜の実行では今週末の予想がまだ作れないことがある。そのときは「出馬表がまだありません」と記録され、月曜の実行や手での再実行で作られる

### タスクスケジューラへの登録(1度だけ)

コマンドプロンプトで、次を実行します(木曜と月曜の夜 21 時)。`C:\パス\KeibaAI` は、このフォルダの場所に置き換えます。

```
schtasks /Create /TN "KeibaAI weekly" /SC WEEKLY /D THU,MON /ST 21:00 /TR "\"C:\パス\KeibaAI\KeibaAI-weekly.bat\""
```

登録の確認は `schtasks /Query /TN "KeibaAI weekly"`、削除は `schtasks /Delete /TN "KeibaAI weekly" /F` です。

### 結果の見方

- `data\weekly.log`:実行のたびに追記される記録。末尾を見る。正常なら次のような行が出る
  - `reviewed: 2026-10-10, 2026-10-11`(回顧を書いた日。なければ `なし`)
  - `forecast 2026-10-17: 142頭`(予想を保存した日と頭数。`出馬表がまだありません` なら、まだ作っていない)
- `data\reviews\<日付>.md`:その日の回顧
- 画面の「回顧」ページ:同じ内容を画面で見られる

### うまくいかないとき

先に `data\weekly.log` の末尾を見ます(エラーはすべてここに出ます)。

| log の内容・症状 | 原因と対処 |
|---|---|
| 「このPCでは JV-Link を呼べません」 | 32bit Python と JV-Link のセットアップが要る。README の「1. JRA-VAN から取り込む」。JV-Link を開き直して JVOpen が -303 を返すときは、時間をおくか、JV-Link を管理者として開き直す |
| `forecast ...: 出馬表がまだありません` | 馬番がまだ確定していない(金曜の枠順の発表前)。あとで再実行する。エラーではない |
| `reviewed: なし` | 回顧できる日がない(予想を保存した日の結果がまだ出ていない、または回顧済み)。エラーではない |
| log が増えない | タスクが動いていない。`schtasks /Query /TN "KeibaAI weekly" /V` で最終実行結果を見る。PC が停止・スリープしていると動かない |
| log に何も出ず、すぐ終わる | `.venv` がない。bat は `.venv` の有無を確かめないので、「KeibaAI.bat」を一度動かして `.venv` のメッセージを確認する |
| 同時に別の取得・画面からの取得が動いている | JV-Link を短い間に何度も開くと失敗することがある。取得が終わってから実行する |

### 手で実行して確かめる

コマンドプロンプトでこのフォルダへ移動して `KeibaAI-weekly.bat` を実行し、そのあと `type data\weekly.log` で記録を見ます(画面には何も出ないのが正常です)。

## KeibaAI-sunday.bat

### 何をするか

`keibaai weekly --after-races` を実行し、出力を `data\weekly.log` の末尾に追記します。

1. 予想を保存した日のうち、今日までの日の結果を取得し、回顧を `data\reviews\<日付>.md` に書く(`KeibaAI-weekly.bat` と違い、今日の分も対象)
2. 学習・評価を実行し、`data\evals\<日付>.md` に書く。評価期間は今日から 1 年前以降(それ以前で学習)で、`keibaai train` と同じ 3 行と、回顧した日ごとの実運用の成績(◎の的中・回収率など)を並べる

今週末の予想は作りません(それは木曜・月曜の `KeibaAI-weekly.bat` の役目です)。

### タスクスケジューラへの登録(1度だけ)

```
schtasks /Create /TN "KeibaAI sunday" /SC WEEKLY /D SUN /ST 18:30 /TR "\"C:\パス\KeibaAI\KeibaAI-sunday.bat\""
```

最終レースの発走は 16:40 前後です。成績の確定を待つため 18:30 にしています。結果がまだ出ていなければ、その日は回顧されず、木曜・月曜の実行で拾われます。
